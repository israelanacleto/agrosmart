====================================================================
AUTOMACAO INTELIGENTE BASEADA EM DADOS - AGROSMART
====================================================================

Codigo:  motor_decisao.py  (Python 3, apenas biblioteca padrao)
Uso:     python motor_decisao.py   (rodar antes 6_Processamento_Dados/processar_dados.py)

--------------------------------------------------------------------
1) TIPO DE AUTOMACAO
--------------------------------------------------------------------
Motor inferencial baseado em regras, com encadeamento progressivo
(forward chaining). Optamos por regras em vez de Machine Learning porque:
  - ainda nao ha historico rotulado suficiente para treinar um modelo;
  - as regras seguem conhecimento agronomico conhecido (limites de
    umidade do solo, molhamento foliar para fungos, VPD);
  - cada decisao e explicavel: o alerta mostra quais regras o geraram.
Quando a camada refined acumular historico com o resultado real das
acoes, o mesmo dataset pode ser usado para treinar um classificador
que substitua ou calibre os limiares das regras.

--------------------------------------------------------------------
2) DADOS QUE O MOTOR INTERPRETA (base de fatos)
--------------------------------------------------------------------
- Leitura atual do talhao: temperatura, UR, umidade do solo, VPD,
  movimento, periodo (dia/noite)
- Janela de 2 h: chuva registrada, leituras perdidas ou rejeitadas
- Janela de 24 h: maximo de horas seguidas com UR >= 85%, temperatura media
- API de clima: probabilidade de chuva prevista, maxima prevista
- Diagnosticos da lavoura (dados_agricolas.csv): quantidade de focos
  fungicos ativos (Ferrugem, Antracnose, Mildio, Mancha Foliar)

--------------------------------------------------------------------
3) REGRAS DE INFERENCIA (derivam fatos novos)
--------------------------------------------------------------------
R01 solo < 30% ........................................ solo_seco
R02 solo < 20% ........................................ solo_critico
R03 solo > 85% ........................................ solo_encharcado
R04 temperatura >= 32 C ............................... calor_intenso
R05 VPD >= 2,0 kPa .................................... ar_seco
R06 solo_seco E (calor_intenso OU ar_seco) ............ estresse_hidrico
R07 chuva no pluviometro nas ultimas 2 h .............. chuva_recente
R08 API preve chuva >= 60% ............................ chuva_prevista
R09 >= 6 h seguidas com UR >= 85% nas ultimas 24 h .... molhamento_prolongado
R10 temperatura media 24 h entre 15 e 28 C ............ temperatura_favoravel_fungo
R11 molhamento_prolongado E temperatura_favoravel ..... ambiente_favoravel_fungo
R12 ha focos fungicos nos diagnosticos ................ inoculo_presente
R13 ambiente_favoravel_fungo E inoculo_presente ....... risco_fungico_alto
R14 movimento no PIR durante a noite .................. intrusao
R15 leitura perdida/rejeitada nas ultimas 2 h ......... falha_sensor

R06, R11 e R13 so disparam porque outras regras ja criaram os fatos de
que dependem: o motor repete o ciclo ate nao surgir nenhum fato novo.

--------------------------------------------------------------------
4) DECISOES AUTOMATIZADAS (regras de acao)
--------------------------------------------------------------------
Acao  Nivel    Quando                                   O que o sistema faz
----  -------  ---------------------------------------  -------------------------------------
A01   CRITICO  solo_critico, sem chuva recente/prevista  registra comando simulado 'I' para irrigacao
A02   ALTO     estresse_hidrico, sem chuva               registra 'I' e recomenda irrigar no horario fresco
A03   ATENCAO  solo_seco (sem estresse)                  programa irrigacao no proximo ciclo
A04   ATENCAO  solo_seco, mas chuva recente/prevista     adia irrigacao (economia de agua)
A05   ATENCAO  solo_encharcado                           registra 'D' (desligar bomba), checar drenagem
A06   ALTO     risco_fungico_alto                        inspecao em 24 h + fungicida preventivo
A07   ATENCAO  ambiente_favoravel_fungo sem inoculo      intensifica monitoramento visual
A08   ALTO     intrusao                                  alerta para verificar cameras/cerca
A09   ATENCAO  falha_sensor                              chamado de manutencao do no de campo

Classificacao de risco do talhao = maior nivel entre as acoes ativas
(NORMAL < ATENCAO < ALTO < CRITICO). Um alerta e emitido so quando a
acao comeca a valer, para nao repetir a mesma mensagem a cada leitura.

As leituras do dia sao reproduzidas em ordem cronologica, como se
chegassem em tempo real. Nesta demonstracao os comandos 'I'/'D' ficam
gravados em saida/comandos_atuadores.txt (e nao voltam para a serie
simulada); por isso o solo de T2 continua secando nos dados. Em campo,
uma integracao futura faria o gateway repassar o comando para a Serial
do no correspondente. Nao ha gateway ou acionamento fisico em execucao.

--------------------------------------------------------------------
5) SAIDAS GERADAS
--------------------------------------------------------------------
