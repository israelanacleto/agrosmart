AGROSMART — GUIA DOS CINCO ITENS DA ENTREGA
=========================================

Executar: python executar_pipeline_integrado.py --gerar-dados
Requer Python 3. Usa somente a biblioteca padrao.
Os HTML e as imagens entregues tambem podem ser abertos sem Python.

1. INTEGRACAO DA ARQUITETURA
4_Arquitetura_Solucao/diagrama_arquitetura.svg (tambem .png)
4_Arquitetura_Solucao/descricao_componentes.txt
Fontes -> processamento -> motor de regras -> dashboard e comandos.
Os componentes planejados sao distinguidos dos scripts executaveis.
O motor le clima JSON e diagnosticos CSV como contexto local.
Arduino/Serial, API ao vivo e atuacao fisica aparecem como propostas;
streaming/Docker e IA generativa sao modulos de execucao separada.
